## 1. Objective

Trả lời các câu hỏi về **so sánh và đặc điểm phân biệt giữa các
Customer Segment** do EPIC-07 + EPIC-08 sản xuất:

## 2. Scope

### 2.1 In scope

- Per-(unit, cluster, feature) **segment comparison matrix**: gom nhặt
  CP-02 statistics (median, P25, P75, count, n_missing, mean, std),
  CP-02 OVERALL statistics, CP-02 relative comparison (median / mean /
  reference status / direction), và CP-03 IQR overlap với OVERALL.
- Per-(unit, feature) **distinguishing feature analysis**: effect range
  (relative % vs OVERALL median), IQR overlap coefficient distribution
  across cluster pairs, direction counts (n_higher / n_lower /
  n_comparable / n_zero_reference), direction consistency ratio, và
  analytical classification.
- Per-(unit, cluster_a, cluster_b, feature) **pairwise IQR overlap
  analysis**: IQR overlap coefficient cho mọi cặp cluster (a < b).
- **Visualisation**: violin plots (per unit × feature) + distinguishing
  feature bar chart + IQR overlap summary heatmap.
- **CP-02 ↔ CP-03 consistency check** (cluster customer counts match).
- Methodology gate: forbidden tokens (segment naming, marketing
  recommendation, ranking, separation score) tested.

### 2.2 Out of scope (deferred to CP-04 → CP-05 hoặc future work)

- Cluster đặt tên ("Champions", "VIP", "Loyal", ...).
- Marketing / campaign recommendation.
- Algorithm comparison / ranking / "best algorithm".
- Composite scoring / ranking framework cho distinguishing features

### 4.3 CP-03 derived indicators

Per-(unit, cluster, feature):
- `iqr_overlap_with_population` — intersection of cluster IQR với
  OVERALL IQR, chia cho `max(IQR_cluster, IQR_OVERALL)` ∈ [0, 1].

Per-(unit, feature):
- `cluster_median_min`, `cluster_median_max` — extremes của cluster
  medians.
- `effect_range` = `cluster_median_max − cluster_median_min` (RAW units).
- `effect_range_rel_pct` = `effect_range / |overall_median| × 100`
  (relative to OVERALL median). NaN nếu `|overall_median| ≈ 0`.
- `iqr_overlap_mean`, `iqr_overlap_median`, `iqr_overlap_min`,
  `iqr_overlap_max` — statistics của pairwise IQR overlap coefficients
  trong unit.
- `n_clusters_assessable` — số cluster có finite median / P25 / P75.
- `n_clusters_higher`, `n_clusters_lower`, `n_clusters_comparable`,
  `n_clusters_zero_reference` — direction counts.
- `direction_consistency_ratio` = `max(n_higher, n_lower) /
  n_clusters_assessable`.
- `classification` — analytical category (see §4.4).

### 4.4 Analytical classification

CP-03 phân loại mỗi (unit, feature) vào một trong các analytical
categories dựa trên **WORKING_ANALYTICAL_THRESHOLD** (xem §4.5):

| Category | Rule |
|---|---|
| `HIGH_DIFFERENCE_OBSERVED` | `effect_range_rel_pct ≥ WORKING_HIGH_DIFFERENCE_EFFECT_PCT` AND `iqr_overlap_mean ≤ WORKING_MODERATE_OVERLAP_MEAN` AND `n_clusters_assessable ≥ MIN_ASSESSABLE_CLUSTERS` |
| `MODERATE_DIFFERENCE_OBSERVED` | `effect_range_rel_pct ≥ WORKING_MODERATE_DIFFERENCE_EFFECT_PCT` AND not HIGH |
| `HIGH_OVERLAP` | `iqr_overlap_mean ≥ WORKING_HIGH_OVERLAP_MEAN` |
| `LOW_DIFFERENCE_OBSERVED` | `effect_range_rel_pct < WORKING_LOW_DIFFERENCE_EFFECT_PCT` |
| `NOT_ASSESSABLE` | `n_clusters_assessable < MIN_ASSESSABLE_CLUSTERS` or NaN inputs |

### 4.5 WORKING_ANALYTICAL_THRESHOLD

| Constant | Value | Meaning |
|---|---|---|
| `WORKING_HIGH_DIFFERENCE_EFFECT_PCT` | 50% | effect_range_rel_pct ≥ threshold → HIGH_DIFFERENCE_OBSERVED |
| `WORKING_MODERATE_DIFFERENCE_EFFECT_PCT` | 15% | effect_range_rel_pct ≥ threshold → MODERATE_DIFFERENCE_OBSERVED |
| `WORKING_LOW_DIFFERENCE_EFFECT_PCT` | 15% | effect_range_rel_pct < threshold → LOW_DIFFERENCE_OBSERVED |
| `WORKING_HIGH_OVERLAP_MEAN` | 0.7 | mean IQR overlap ≥ threshold → HIGH_OVERLAP |
| `WORKING_MODERATE_OVERLAP_MEAN` | 0.5 | mean IQR overlap ≤ threshold (kết hợp HIGH effect range) → HIGH separation |
| `MIN_ASSESSABLE_CLUSTERS` | 2 | dưới threshold → NOT_ASSESSABLE |
| `OVERALL_MEDIAN_FLOOR` | 1e-9 | numerical guard cho effect_range_rel_pct |
| `IQR_WIDTH_FLOOR` | 1e-12 | numerical guard cho IQR overlap coefficient |

**These thresholds are NOT research-grade.** Chúng là conservative
analytical defaults cho descriptive classification. Một reader (hoặc
mentor) có thể thay đổi threshold và re-bin classification mà KHÔNG
cần sửa CP-03 source code — các distinguishing indicators
(`effect_range_rel_pct`, `iqr_overlap_mean`, direction counts) là
primary evidence surface, classification là derived view.

### 4.6 IQR overlap coefficient

For two cluster (or cluster-vs-population) IQRs:

```
IQR_A = [P25_A, P75_A]
IQR_B = [P25_B, P75_B]

intersection_width = max(0, min(P75_A, P75_B) - max(P25_A, P25_B))
iqr_overlap        = intersection_width / max(IQR_A width, IQR_B width)
```

Properties:

- Bounded in [0, 1].
- 1.0 = identical IQRs.
- 0.0 = disjoint IQRs.
- NaN if either P25 / P75 is NaN.
- For both zero-width IQRs: 1.0 if medians equal, 0.0 otherwise.

### 8.4 Why no PCA / UMAP?

CP-03 brief §11 explicitly notes: "Không bắt buộc PCA / UMAP nếu
boxplot / violin / heatmap đã đủ evidence." CP-02 boxplots + CP-03
violin plots + heatmaps đủ để mô tả distribution và overlap. PCA /
UMAP multivariate visualisation không thuộc CP-03 scope vì:

- CP-03 chỉ trên RAW feature values, không trên transformed space.
- CP-03 không cần cluster quality score — chỉ cần evidence về
  feature-level overlap / separation.
- Multivariate visualisation có thể đánh lừa về cluster separation
  trong không gian 2D; CP-03 tránh điều này.

## 9. Findings

### 9.1 Cross-algorithm observations (descriptive only)

Trên cùng dataset CP-01 / CP-02 (FE06-v1.0, RFM Extended, 4,371
customers × 14 features, EXP-01 working-default):

- **Recency, Frequency, Monetary, TotalQuantity, TenureDays, ActiveDays,
  PurchaseIntervalMean, PurchaseIntervalStd** consistently
  HIGH_DIFFERENCE_OBSERVED across cả 5 algorithms — đây là những
  feature phân biệt cluster rõ nhất về mặt median-based effect range
  VÀ IQR overlap.

- **AverageInvoiceValue** consistently HIGH_OVERLAP — cluster
  distributions overlap nhiều, khả năng phân biệt thấp.

- **AverageQuantity ↔ BasketSize** HIGH_OVERLAP và redundant
  (Pearson = 1.0 per FE-06) — chỉ nên diễn giải như 1 feature
  độc lập.

- **ProductsPerInvoice** MODERATE_DIFFERENCE_OBSERVED — phân biệt
  vừa phải giữa các cluster.

- **CancellationRate ↔ ReturnRate** NOT_ASSESSABLE (Pearson = 1.0 per
  FE-06 + ZERO_REFERENCE cho OVERALL median ≈ 0). CP-03 không tính
  được relative percentage.

- **Frequency ↔ ActiveDays** HIGH_DIFFERENCE_OBSERVED cả hai
  (HIGH_CORRELATION = 0.97 per FE-06 nhưng không phải duplicate) —
  hai feature vẫn mang thông tin độc lập (calendar-day vs invoice
  count).

### 9.2 Per-algorithm specific observations

- **K-Means / Agglomerative / GMM / FCM** (K=4) cho thấy
  classification profile gần giống nhau cho 14 features, do cùng
  input matrix + cùng K.
- **DBSCAN (K_realized=17)** có `n_clusters_assessable` thấp hơn
  (clusters rất nhỏ có std NaN), dẫn đến một số feature được
  classify `NOT_ASSESSABLE` thay vì HIGH/MODERATE.

### 9.3 KHÔNG ranking / KHÔNG winner

CP-03 KHÔNG tuyên bố algorithm nào "tốt nhất" trong việc phân biệt
cluster. Số lượng feature HIGH_DIFFERENCE_OBSERVED phụ thuộc vào K
(DBSCAN K_realized=17 so với fixed-K=4) và vào distribution shape, không
phải cluster quality. Mỗi algorithm được mô tả độc lập.
