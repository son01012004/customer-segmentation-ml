## 4. Naming Framework

### 4.1 RFM core tiers

| Tier | Rule | Interpretation |
|---|---|---|
| **Recency: Recent** | direction=LOWER | Recency thấp hơn population median → mua gần đây hơn |
| **Recency: Older** | direction=HIGHER | Recency cao hơn → lần mua xa hơn |
| **Recency: Mixed** | direction=COMPARABLE/NA | Không tách bạch rõ |
| **Frequency: Frequent** | direction=HIGHER | Nhiều invoice hơn |
| **Frequency: Occasional** | direction=LOWER | Ít invoice hơn |
| **Frequency: Mixed** | direction=COMPARABLE/NA | Không tách bạch rõ |
| **Monetary: HighValue** | direction=HIGHER | Chi tiêu (GBP) cao hơn |
| **Monetary: LowValue** | direction=LOWER | Chi tiêu thấp hơn |
| **Monetary: Mixed** | direction=COMPARABLE/NA | Không tách bạch rõ |

### 4.2 Behavioural modifiers

Modifier được thêm khi feature có **direction=HIGHER** VÀ
**classification=HIGH_DIFFERENCE_OBSERVED** trong CP-03:

| Modifier | Rule | Interpretation |
|---|---|---|
| **LongTenured** | TenureDays HIGHER + HIGH | Quan hệ dài hơn |
| **IrregularCadence** | PurchaseIntervalStd HIGHER + HIGH | Cadence biến động lớn, gap giữa mua khó dự đoán |
| **Bulk** | TotalQuantity HIGHER + Monetary HIGHER (cả hai HIGH) | Nhiều items + giá trị cao mỗi invoice |
| **Active** | ActiveDays HIGHER + HIGH + Frequency direction ≠ ActiveDays direction | Calendar-level activity độc lập với invoice count |

### 4.3 Construction rules

1. Ghép `[RecencyTier] [FrequencyTier]` làm core name.
2. Thêm MonetaryTier nếu:
   - Monetary direction ≠ Frequency direction, HOẶC
   - Cả Frequency VÀ Monetary đều = HIGHER.
3. Thêm behavioural modifier cuối cùng nếu thỏa §4.2.
4. Tổng số từ ≤ 4.
5. Nếu không thỏa điều kiện nào → "Comparative Segment A/B/C" + rationale.

### 4.4 Hard constraints (NO)

- **NO marketing terms** ("loyal", "champion", "VIP", "at-risk") trừ khi
  dataset trực tiếp hỗ trợ.
- **NO CancellationRate / ReturnRate** → `NOT_ASSESSABLE` (CP-03) → KHÔNG
  làm naming evidence.
- **NO AverageQuantity ↔ BasketSize redundancy** (Pearson = 1.0) → chỉ coi
  như 1 evidence độc lập.
- **NO NaN interpretation** → PurchaseIntervalMean/Std structural NaN
  KHÔNG được diễn giải như quan sát trực tiếp.
- **NO cross-algorithm cluster ID mapping** → K-Means C1 ≠ GMM C1.
